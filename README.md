# 📱 Estudio de bolsillo

El Estudio de grabación del Generador de Videos como app para el celular: teclado, pads, acompañamiento, arreglo y efectos, sin internet.

Abrir en Chrome (Android): https://victornetroski.github.io/estudio-bolsillo/ → menú ⋮ → **Instalar app**.

Este repositorio solo tiene la app ya armada (se publica desde el proyecto principal con `node bolsillo/construir.mjs`).
Sonidos: MuseScore General SoundFont (MIT) y Versilian Community Sample Library (CC0, dominio público); ver `sonidos/LICENCIA-*`.
